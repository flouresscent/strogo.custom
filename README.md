# Strogo Custom

Локальный интерактивный прототип нового направления Strogo Shop. Две страницы: `/custom` и `/custom/create`. Корень `/` также показывает лендинг.

27 октября 2026: лендинг получил самостоятельное мягкое премиальное оформление, отдельную шапку и scroll-сцену от крупного принта к галерее ковриков. Конструктор сохраняет прежнее оформление и функциональность. Детали и источники новых материалов — в [docs/LANDING_REDESIGN.md](docs/LANDING_REDESIGN.md).

Текущая версия: тёмная тема, шапка по предоставленным исходникам Apple, оптимизированный hero с независимым исчезновением текста и симметричной сеткой, интерактивный полноэкранный обзор цветов/размеров/дизайна. Подробности, источники и замеры до/после — в [docs/DARK_LANDING.md](docs/DARK_LANDING.md).

## Запуск

Требуется Node.js 22.12+ (проверено на Node.js 26), npm.

```sh
npm install
npm run dev
```

Откройте http://127.0.0.1:5173/custom. Для демонстрации после сборки: `npm run build`, затем `npm run preview` (http://127.0.0.1:4173/custom).

## Возможности

- Лендинг: переключение трёх оригинальных принтов, форматов, визуальные шаги, FAQ, мобильная навигация и ссылки в магазин.
- Редактор: PNG/JPEG/WebP, проверка сигнатуры и размеров, предварительный просмотр и замена, слои изображения/текста, перетаскивание мышью и касанием, маркеры масштаба/поворота, числовые настройки, выравнивание, заполнение/вписывание, история.
- Фон: пресеты, произвольный цвет, HEX и пипетка из реальных пикселей исходного изображения. Полупрозрачный пиксель смешивается с выбранным фоном; полностью прозрачный отклоняется с пояснением.
- Физические размеры: 900 × 400 и 490 × 420 мм. Объекты хранятся в мм, а смена размера меняет границу области без накопительного смещения. Выход за край объясняется предупреждением.
- Сцена стола: отдельные положение/поворот коврика, клавиатуры и мыши. Её настройки не меняют печатные координаты.
- Сохранение проекта с оригиналами изображений в IndexedDB, предложение восстановить после открытия; явный сброс сохранённого черновика.
- PNG-превью шириной 2400 px содержит дизайн без интерфейса, стола и предметов. Приблизительная оценка DPI учитывает физический размер изображения; порог 150 DPI вынесен в `src/editor/domain.ts`.
- Демо-корзина хранит отдельный снимок проекта локально через заменяемый адаптер `src/checkout.ts`.

## Структура

```text
src/
  App.tsx, main.tsx, styles.css     навигация, оболочка, токены
  landing/Landing.tsx, landing.css презентационная страница
  editor/
    Editor.tsx, editor.css         интерфейс и взаимодействия
    domain.ts                     модель в мм, геометрия, история, валидация
    render.ts                     Canvas2D, пипетка, PNG
    upload.ts                     проверка и декодирование файлов
    persistence.ts                IndexedDB черновик
    domain.test.ts                регрессии доменной модели
  checkout.ts, checkout.test.ts    изолированная демо-корзина
public/assets/                    локальные принты, логотип и шрифт
tests/prototype.spec.ts           браузерные сценарии
docs/                            аудит, ограничения, результаты, скриншоты
```

## Проверки

```sh
npm run typecheck
npm test
npm run build
npm run format:check
npm run test:browser
```

Браузерные тесты используют установленный Google Chrome через Playwright, без отдельной загрузки браузера. Сервер поднимается автоматически, если порт 5173 свободен. Подробные фактически выполненные проверки — в [docs/VERIFICATION.md](docs/VERIFICATION.md).

## Данные и интеграция

Пользовательские изображения не отправляются в интернет. Оригиналы хранятся только в памяти и, после явного сохранения, в локальном IndexedDB. Это не резервная копия: очистка данных сайта удаляет проекты и демо-корзину. Для удаления черновика используйте «Начать заново»; для удаления всех локальных данных очистите данные сайта в браузере.

Цена, производство, доставка и коммерческие условия Custom не подтверждены. Приложение не создаёт реальные заказы, не принимает оплату и не отправляет данные в Tilda. PNG — визуальное превью, а не производственный макет. Перспектива, тканевая текстура и швы — приблизительная CSS-визуализация.

Для будущего размещения на домене нужно настроить отдачу `index.html` для `/custom` и `/custom/create` и статических ресурсов из `dist`. Изменений страниц основного магазина нет. Будущий backend должен заменить адаптер корзины, хранить версии дизайна и оригиналы, валидировать конфигурации на сервере и подтверждать оплату доверенным способом. До запуска необходимо согласовать цены, характеристики, DPI, припуски, цветовые профили, права на материалы и условия обработки пользовательских файлов.

Логотип и TildaSans получены с официального сайта для согласованной демонстрации. Их лицензии для самостоятельного публичного распространения не проверены; источники указаны в [docs/BRAND_AUDIT.md](docs/BRAND_AUDIT.md).

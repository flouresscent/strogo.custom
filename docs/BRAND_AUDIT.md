# Источники и визуальные решения

Дата проверки: 26 октября 2026 года.

Изучены https://strogo.shop/ и https://strogo.shop/darkness через веб-инструмент. HTML главной и подключённый CSS дополнительно скачаны для проверки конкретных значений.

## Подтверждено исходными файлами

- Главная использует Tilda. CSS `https://static.tildacdn.com/ws/project13906589/tilda-blocks-page185690109.min.css` задаёт `--t-headline-font` и `--t-text-font` как `TildaSans,Arial,sans-serif`. Встроенный HTML содержит fallback Arial; наличие Arial в HTML само по себе не определяет итоговый шрифт.
- Навигация: чёрный фон, белый текст, красные active/hover-состояния (`#ff0000`), тонкая белая граница с низкой прозрачностью. Исходный desktop menu text 18px/400; логотип 50px на desktop и 28px до 960px.
- Используются монохромные поверхности, крупные изображения ковриков, названия «Новая коллекция», «Премиум ковры», «Поддержка».
- На Darkness описаны прошитые края, мягкое основание и формат 49 × 42. Эти свойства не перенесены как подтверждённые производственные обещания для Custom.
- Ссылки магазина: `https://strogo.shop/catalog`, `https://strogo.shop/darkness`, `https://t.me/strogoMagaz`; юридические страницы `/return`, `/public`, `/privacy`.

## Осознанные приближения

Прототип сохраняет монохромную основу, красный акцент, шрифт и связи с магазином. Светлые секции лендинга и рабочая область редактора — продуктовая адаптация для читаемости, а не заявление о точном воспроизведении исходной страницы. Точные интервалы, композиция и CSS-сцена разработаны для Custom. Коврик, швы, клавиатура и мышь в hero — CSS/Canvas-композиция с локальным принтом, не фотография товара и не точная симуляция печати.
